# character-circumstances-with-style

Make character circumstances travel with style files.

## Settled

- Not a new always-loaded skill.
- Pair **style files** (how they sound) with **character files** (history, circumstances, current knowledge) wherever style is an input to writing or simulating a character.
- Mismatch default: write to the request, flag the contradiction, report on the next author-facing turn. Do not silently patch wiki.
- Wiki updates wait for author confirmation.
- Story-planning backstory stays exploratory.
