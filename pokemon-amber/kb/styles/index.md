# Style Guidance Index

Load the smallest relevant guide before drafting or revising. These files record
current approved direction, not a replacement for chapter context.

## Start with

- [Story tone](tone.md) for reader effect and tonal movement.
- [Amber narration](char-amber-narration.md) for first-person voice.
- [Amber dialogue](char-amber-dialogue.md) for spoken interaction.
- [Emotional scenes](scene-emotional.md), [battle/action](scene-battle.md), or
  [tension](scene-tension.md) for scene-specific technique.

Load character guides only when that character is present: [Erika](char-erika.md),
[Fuji](char-fuji.md), [Oak](char-oak.md), and [supporting voices](char-supporting.md).

## Evidence boundary

Quoted [chN] lines are small, verified exemplars of the local principle. They
do not certify an entire chapter, authorize surrounding unreviewed prose, or
settle plot and canon questions. Draft excerpts remain provisional; style
guidance does not resolve disagreements between chapter prose and plans.
